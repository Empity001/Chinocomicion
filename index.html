Volter

Cambios posteriores. Todo lo que no figure como «Acordado» ya se incluyó como cortesía. Cualquier cambio o mejora nueva se considera un servicio aparte y se acuerda antes.

No incluido

  • Otras armas ni otros tipos de munición.
  • Animaciones propias avanzadas (por ejemplo con GeckoLib) ni sonidos propios.
  • Más modos de disparo.
  • Pruebas en servidor dedicado o multijugador (el mod se probó en un jugador).
  • Cambios o mejoras posteriores a la entrega: se acuerdan y cobran aparte.

06 · Instalación

Instalación

  1. Tener Minecraft Java 1.21.1 con NeoForge 21.1.x (Java 21).
  2. Copiar volter-1.0.0.jar a la carpeta mods de esa instalación.
  3. Abrir el juego. El arma está en la pestaña Volter del creativo.
  4. En un servidor, el mod debe estar en el servidor y en cada cliente.

Dependencias

Obligatorias
  • Minecraft Java 1.21.1versión exacta del juego
  • NeoForge 21.1.xel cargador de mods · neoforged.net
  • Java 21lo trae el launcher oficial de Minecraft

Volter no necesita ningún otro mod para funcionar.

Opcionales (solo para ver las recetas)
  • EMIprobado · modrinth.com/mod/emi
  • JEIsin probar · modrinth.com/mod/jei
  • REIsin probar · modrinth.com/mod/rei

Instala solo uno de los tres, en la versión para NeoForge 1.21.1.

Importante. Se probó en un jugador. Servidor dedicado y multijugador no se han probado todavía. No necesita otros mods; con EMI, JEI o REI aparecen las recetas solas.
